# Commit-pinned code audit

This is an adaptive purposive convenience sample:42 candidate repositories were considered,
39 snapshots could be inspected,14 segmentation scopes were reviewed,12 had assessable
vessel training paths and11 contained assessable Python Dynamic Snake implementations.
Current CE-Net optic-disc defaults and VascLinkNet preview-only placeholders are explicitly
excluded from the twelve-path denominator. Nonmatching DSConv acronyms, missing modules,
unverifiable releases and an opaque compiled-backend wrapper are excluded from the port count.

The evidence table retains repository, immutable commit, source path, exact line interval,
public URL and whole-file SHA256. Downloaded source text and excerpts are intentionally
not distributed. Follow the reference or run the online verifier to check frozen evidence.
Manual review traced data origins, evaluated quantities and checkpoint branches together;
function names, callback labels and separate directories alone do not establish test leakage.

Two eligible paths maximize the code-defined evaluation/test metric; four maximize/minimize
validation metrics; two use training loss; three save periodically; one overwrites last weights.
The onurboyar training-loss path monitors test data but does not select by its metric.
LadderNet/DUNet functions named test use held-out training patches, not benchmark test images.
SA-UNet's validation monitor has save_best_only=False. Separate validation directories leave
their source-image/patient independence unknown. Retina-VesselNet chooses held-out training
images before creating new patches, but pre-generated contents and patient independence are
not verified. Serp-Mamba is classified from its documented training entry point, not from the
bundled alternative framework. Missing seed/search disclosure means not established in the
bounded reviewed path, not that authors never tuned or ran other seeds.

Four ports retain sample-offset cancellation and were reproduced on CPU with inspected
numerical gather functions only, without repository entry-point execution. Both morphs,
batch1/4 and constant inputs produce the expected source/gradient pattern (16 controls).
Seven use batched grid sampling and lack that cancellation in the selected implementation;
this does not prove full operator correctness. The four bug-bearing ports contain only two
distinct gather-function AST fingerprints, showing correlated copying.

No community prevalence estimate, independent adoption estimate, actual paper execution,
private dataset identity or author-intent judgment follows from these counts. Public code
observations and measured effects in the controlled DSCNet experiments are separate evidence.
The published protocol/port CSVs preserve each row's scope and limitations. Rebuilding means
verifying references and counts; it does not substitute automated rules for manual judgments.
